**Agrégation** : Processus consistant à combiner plusieurs données pour en obtenir une synthèse, par exemple via des sommes ou des moyennes.

**Analyse multidimensionnelle** : Examen des données selon plusieurs angles ou dimensions, souvent réalisé à l'aide de tableaux croisés dynamiques.

**AVERAGEIF** : Fonction permettant de calculer la moyenne des cellules qui répondent à un critère spécifique.

**CONCAT** : Fonction utilisée pour assembler ou lier plusieurs chaînes de caractères en une seule.

**Contrôle de cohérence** : Vérification visant à s'assurer que les données sont logiques et respectent les règles métier définies.

**COUNTIF** : Fonction permettant de compter le nombre de cellules répondant à un critère précis.

**CSV** : Format de fichier texte simple où les données sont séparées par des délimiteurs (souvent des virgules).

**Dashboard** : Tableau de bord interactif regroupant des indicateurs visuels pour piloter une activité et faciliter la décision.

**DATEDIF** : Fonction calculant la différence entre deux dates en jours, mois ou années.

**DATEVALUE** : Fonction convertissant une date stockée sous forme de texte en un format de date reconnu par Excel.

**Data Visualisation** : Art de transformer des données chiffrées en représentations graphiques claires et parlantes.

**EDA (Exploratory Data Analysis)** : Analyse exploratoire visant à examiner les données pour en comprendre les caractéristiques principales avant une analyse approfondie.

**Encodage** : Format technique définissant la manière dont les caractères sont représentés informatiquement (ex: UTF-8).

**FILTER** : Fonction permettant de filtrer dynamiquement un ensemble de données selon des critères définis.

**IFERROR** : Fonction de gestion d'erreur qui renvoie une valeur personnalisée si une formule génère une erreur.

**IFNA** : Fonction spécifique permettant de gérer les erreurs de type #N/A (valeur non disponible).

**LOWER** : Fonction transformant l'intégralité d'un texte en minuscules.

**Mise en forme conditionnelle** : Outil changeant automatiquement l'apparence d'une cellule selon la valeur qu'elle contient.

**Normalisation** : Action d'uniformiser les données (casse, format, espaces) pour rendre l'analyse plus fiable.

**QUERY** : Requête structurée utilisée pour extraire, filtrer ou transformer des données provenant d'un tableau.

**SORT** : Fonction permettant de trier automatiquement une plage de données.

**Storytelling** : Méthode de communication consistant à raconter une histoire autour des données pour rendre les conclusions plus percutantes.

**SUBSTITUTE** : Fonction permettant de remplacer une partie d'un texte par un autre texte.

**SUMIF** : Fonction permettant d'additionner des valeurs selon un critère spécifique.

**Tableau croisé dynamique (TCD)** : Outil puissant de synthèse permettant de croiser et de manipuler des données de manière interactive.

**TRIM** : Fonction supprimant les espaces superflus au début, à la fin ou entre les mots d'un texte.

**UPPER** : Fonction convertissant un texte en majuscules.

**Valeurs aberrantes** : Données extrêmes ou anormales qui s'éloignent significativement de la tendance générale.

**Valeurs manquantes** : Données absentes ou non renseignées dans un jeu de données, nécessitant un traitement spécifique.

**Validation des données** : Fonctionnalité limitant le type de données ou les valeurs que les utilisateurs peuvent saisir dans une cellule.

**VLOOKUP** : Fonction de recherche verticale permettant de retrouver une valeur dans une colonne précise.

**XLOOKUP** : Fonction de recherche moderne et flexible permettant de trouver une correspondance dans n'importe quelle direction.
